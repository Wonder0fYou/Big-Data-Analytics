### (а) Поиск наибольшего числа
*   **Фаза 1:** Mapper читает числа и распределяет их по корзинам (используя остаток от деления `abs(num) % N`). Reducer находит максимальное число в каждой корзине
*   **Фаза 2:** Mapper добавляет ко всем локальным максимумам единый ключ `global_max`. Reducer находит среди них одно самое большое число

### (б) Поиск среднего арифметического
*   **Фаза 1:** Mapper распределяет числа по корзинам. Reducer считает сумму чисел и их количество внутри своей корзины
*   **Фаза 2:** Mapper отправляет пары `(сумма, количество)` с ключом `total_avg`. Reducer складывает все суммы, все количества и делит первое на второе

### (в) Исключение дубликатов
*   **Фаза 1:** Mapper выдает само число в качестве ключа. Reducer выводит ключ только один раз при его смене
*   **Фаза 2:** Mapper добавляет ключ `distinct`, чтобы собрать все уникальные числа в один итоговый файл

### (г) Подсчет различных целых чисел
*   **Фаза 1:** Reducer вместо самого уникального числа выводит просто цифру `1`
*   **Фаза 2:** Mapper добавляет ключ `count` к каждой единице. Reducer суммирует все единицы и получает точное количество уникальных чисел

## Особенности хранения ОБФЦЧ (Очень Большого Файла Целых Чисел)

**Ключевые особенности хранения:**
1. **Блочное разделение:** Файл разбивается на блоки фиксированного размера
2. **Распределенность:** Эти блоки распределяются по множеству узлов в кластере.
3. **Репликация:** Каждый блок копируется на несколько узлов. Если один сервер выйдет из строя, данные не потеряются и будут доступны с другого узла.
4. **Локальность данных:** При запуске MapReduce вычисления отправляются туда, где физически лежат данные. Это минимизирует передачу огромных объемов данных по сети.
